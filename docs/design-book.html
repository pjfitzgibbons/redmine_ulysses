Ulysses design book

The reference theme, read live from assets/stylesheets/tokens.css: every property of the --uly-* contract, in light and dark. A site's public/ulysses/theme.css overrides any of them; the README's theme guide says how.

Colour

Each colour role in both modes. A theme sets a role in :root for light and again under @media (prefers-color-scheme: dark) for dark; a light value the dark block leaves out applies in dark too.

Contrast

The pairs the theme check measures, as in RedmineUlysses::Theme::PAIRS: text on its grounds at 4.5:1 or better, and header text at 5.6:1. bin/rake redmine_ulysses:theme:check[FILE] fails a theme under either.

In use

The roles together, the way Redmine's header, buttons, flashes and text use them.

Type

IBM Plex, vendored under the SIL Open Font License: Sans for text, Serif for the project name in the header, Mono for code.

Motion

Hover or focus a track to see each duration with the easing. Under prefers-reduced-motion: reduce both durations are 0ms.
